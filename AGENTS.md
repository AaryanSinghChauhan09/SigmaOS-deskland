# SigmaOS-deskland — Agent Guidelines

## Component Purpose
Desktop environment built on Wayland/Hyprland with a Rust configuration engine for managing monitors, workspaces, keybinds, and window rules.

## Principles Applied
- Single Responsibility
- Error Handling
- Memory Safety
- Safe Concurrency

## Do Not
- Use unsafe code
- Hardcode credentials
- Skip error handling

## Testing
Run: cargo test
